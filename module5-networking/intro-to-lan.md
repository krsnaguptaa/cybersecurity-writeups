# Intro to LAN
Star = reliable, costly | Bus = slow, cheap | Ring = one break = all down
Subnetting = splitting network for security
(cafe example: staff and public wifi separated)
Default gateway = router = door to internet
ARP = finds MAC from IP, risk = ARP poisoning
DHCP = auto assigns IP (DORA process)
iPhone hotspot = router + DHCP server in pocket
