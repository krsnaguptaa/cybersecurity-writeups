# OSI Model
7 layers - "Please Do Not Throw Sausage Pizza Away"
7-Application = Chrome, HTTP, DNS
6-Presentation = encryption, SSL
5-Session = keeps multiple connections separate
4-Transport = TCP/UDP, ports
3-Network = IP, routing, routers
2-Data Link = MAC, switches, local delivery
1-Physical = cables, wifi, raw bits
Encapsulation = adding headers while sending
Decapsulation = removing headers while receiving
